Teste de Tags

Tag Header:

A tag header em HTML serve para criar um bloco de conteúdo introdutório ou de navegação.Ela agrupa elementos como logotipos, menus de links, títulos e formulários de busca no topo de uma página ou de uma seção específica.

Tag main:

A tag main no HTML serve para marcar e definir o conteúdo principal de uma página ou aplicativo web. Ela indica a parte mais importante do documento, que tem foco no assunto central ou na função principal daquela tela.

Tag nav:

O elemento nav no HTML serve para criar uma seção de uma página dedicada a links de navegação. Ele ajuda navegadores, robôs de busca e leitores de tela a entenderem que aquele bloco de código forma um menu principal ou uma área importante para guiar o usuário pelo site.

Tag section:

A tag section serve para agrupar conteúdos que possuem o mesmo tema ou assunto em uma página web. Ela é um elemento semântico do HTML5, o que ajuda leitores de tela e motores de busca a entenderem a estrutura do site.

Tag article:

A tag HTML article serve para definir um conteúdo independente e autossuficiente, que faz sentido por si só e pode ser distribuído ou reutilizado isoladamente (como um post de blog, notícia, comentário de usuário ou cartão de produto). Ela melhora a semântica, a acessibilidade e o SEO da página.

Tag aside:

A tag aside do HTML5 serve para marcar uma seção de uma página com conteúdo que se relaciona de forma indireta ou secundária com o texto principal ao seu redor. Ela funciona como um bloco complementar, muitas vezes exibido em barras laterais (sidebars).

Tag figure:

A tag figure no HTML serve para agrupar um conteúdo independente — como fotos, ilustrações, diagramas ou códigos — junto com uma legenda opcional, tratando tudo como uma única unidade que pode ser movida sem alterar o sentido do texto principal.

Tag footer:

A tag footer em HTML serve para criar o rodapé de uma página web ou de uma seção específica. Ela é um elemento semântico que indica aos navegadores e mecanismos de busca que o conteúdo ali dentro encerra um bloco de informação, contendo dados como direitos autorais, contatos ou links úteis.
