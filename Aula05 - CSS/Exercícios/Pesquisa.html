Seletores

Seletor Atributo:

Um seletor de atributo em CSS é um recurso que permite estilizar elementos HTML com base na presença, no valor ou em partes do valor de um atributo específico (como type, href, target ou atributos personalizados data-*).

Seletor Descendente

O seletor descendente em CSS é um combinador representado por um espaço em branco ( ) entre dois seletores, usado para aplicar estilos a elementos que estão aninhados dentro de outros.

Seletor Filho Direto

O seletor de filho direto (ou combinador de filho) em CSS é representado pelo símbolo de maior que (>) e serve para selecionar apenas os elementos que são filhos imediatos de um elemento pai específico, ignorando netos ou outros descendentes mais distantes.

Seletor Adjacente Direto

O seletor adjacente direto (ou seletor de irmão adjacente) em CSS seleciona um elemento que está imediatamente após outro elemento específico, compartilhando o mesmo elemento pai.

Seletor de irmãos Gerais

O seletor de irmãos gerais no CSS é um combinador representado pelo símbolo de til (~). Ele serve para selecionar todos os elementos irmãos que aparecem depois de um elemento especificado, desde que estejam no mesmo nível hierárquico (compartilhando o mesmo elemento pai)

Seletor de PseudoClasse

Um seletor de pseudoclasse em CSS é uma palavra-chave adicionada a um seletor que define um estado especial ou uma condição específica de um elemento. Ela é indicada pelo símbolo de dois-pontos (:) e não altera o HTML, mas muda o estilo do elemento dinamicamente de acordo com a interação do usuário ou a sua posição na estrutura da página
